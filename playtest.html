How to playtest

Select a token (the P1–P6 buttons, the token itself, or keys 1–6). Move orthogonally with arrow keys, WASD, or by clicking an adjacent cell. A hidden cell reveals a random unused room and keeps it. Tokens may share a cell. The 9×9 map has a visible edge.

A little more
  1. All tokens begin in the Starting Hall at the center.
  2. Use the move log to remember leaves and enters when resolving effects by hand.
  3. If an effect sends a token back, use Return to start. Destroyed rooms and other card effects are not automated.
  4. The board is saved in this browser until you start a new game.
